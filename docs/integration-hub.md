# Integration and Data Quality Hub

The integration portfolio is available at `/integrations`, with the connector catalogue at `/integrations/catalog` and setup entry at `/integrations/new`. Integration workspaces provide URL-backed overview, configuration, authentication, mappings, synchronization, runs, data-quality, source-records, webhooks, access, and activity routes.

The hub never fabricates operational synchronization data. Unimplemented capabilities are shown explicitly.
