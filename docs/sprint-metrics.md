# Sprint metrics

| Metric | Formula | Direction | Missing data |
|---|---|---|---|
| Predictability | Completed originally committed points / original points × 100 | Higher | `UNKNOWN` |
| Commitment achievement | Completed committed points / committed points × 100 | Higher | `UNKNOWN` |
| Velocity | Completed points in sprint | Contextual | `UNKNOWN` |
| Carryover | Incomplete originally committed points / original points × 100 | Lower | `UNKNOWN` |
| Scope change | (Points added + points removed) / original points × 100 | Lower | `UNKNOWN` |
| Blocked ratio | Blocked active points / active points × 100 | Lower | `UNKNOWN` |
| Blocker age | Sum of active blocker ages / active blocker count | Lower | `UNKNOWN` |
| Defect rate | Defects created in sprint / completed work items | Lower | `UNKNOWN` |

Every metric contract carries unit, health status, comparison period, sample size, calculation time, completeness, definition version, and explanatory definition. Added-after-start work never changes the original commitment denominator.
