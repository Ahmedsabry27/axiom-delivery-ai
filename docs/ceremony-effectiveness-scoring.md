# Ceremony effectiveness scoring

Checklist completion is completed eligible weight divided by eligible weight. Evidence coverage is completed evidence-required items with authorized evidence divided by eligible evidence-required items. These are displayed separately.

Effectiveness configuration `ceremony-effectiveness-v1` weights preparation 20%, evidence 15%, decision completion 20%, action quality 15%, previous action closure 15%, and outcome achievement 15%. The API returns inputs, weights, missing dimensions, version, and sufficiency. A value remains unknown until at least half of configured weight has evidence.
