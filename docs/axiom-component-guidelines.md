# Axiom component guidelines

Use `Button` for actions and links for navigation. `StatusBadge` always displays text plus an icon, treats unknown explicitly, and does not represent confidence. Use `Confidence` for evidence confidence. `Surface`, `KpiCard`, `FormField`, `Tabs`, `PageHeader`, and `StatePanel` provide the shared molecule vocabulary.

Inputs require persistent labels. Errors must be adjacent and announced. Numeric cells use tabular figures and right alignment. Interactive surfaces require native interactive elements or keyboard semantics. Heavy charts, designers, and workbenches stay route-lazy.
