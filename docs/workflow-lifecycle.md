# Workflow lifecycle

The durable lifecycle values are `DRAFT`, `IN_REVIEW`, `APPROVED`, `PUBLISHED`, `PAUSED`, and `RETIRED`. This delivery implements draft creation, draft-only editing, published-definition immutability, normal-run blocking for unpublished workflows, retirement, and activity records.

Approval-backed review/publication and pause/resume transitions remain to be connected before AX-WF01 can be considered functionally complete.
