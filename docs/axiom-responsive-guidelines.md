# Axiom responsive guidelines

Desktop uses the stable sidebar and dense grids. Laptop reduces grid columns without hiding primary navigation. Tablet uses two-column metrics and stacked supporting panels. Mobile uses one column, horizontally scrollable tabs, card alternatives for complex tables, reachable actions, and internally scrolling dialogs.

Validate at 1440×900, 1024×768, 768×1024, 375×812, and 375×667. Pages must not introduce horizontal document overflow. The legacy bridge makes full-screen wizards fit short mobile viewports while migration continues.
