# Axiom accessibility guidelines

Target WCAG 2.2 AA: semantic landmarks and heading order, visible focus, keyboard access, persistent labels, announced errors/loading, named icon buttons, table headers and sort state, text-backed status, reduced motion, adequate targets, and chart summaries/table alternatives.

Do not disable focus, labels, status text, error messages, or accessible names. Unknown and insufficient evidence are explicit states. Dialog implementations must trap focus, close on Escape, return focus, and clean up scroll locks.
