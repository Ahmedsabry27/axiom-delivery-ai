# Agile anti-pattern rules

Version 1.0 detects system-level signals only:

- Mid-sprint scope injection above 10% of original commitment.
- Active blockers older than 3 days.
- Work in progress above 8 items.
- QA queue above 3 items.
- Backlog readiness below 75%.
- Carryover above 20% across the measured period.

Each result exposes observed value, threshold, severity, affected evidence where available, and a process-focused intervention. Rules must never score individuals, infer motivation, or attribute blame. Recommendations require evidence and create only editable drafts for human review.
