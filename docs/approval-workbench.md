# Approval Workbench

The Axiom approval workbench uses `/approvals` for the current identity's authorized inbox, `/approvals/submitted` for requester-owned proposals, `/approvals/history` for terminal records, and `/approvals/delegations` for delegation administration. Approval details use URL-backed overview, proposal, evidence, impact, execution, and activity tabs.

All collection and detail data comes from authenticated APIs. The existing Action Center remains authoritative and related approvals/actions link to each other.
